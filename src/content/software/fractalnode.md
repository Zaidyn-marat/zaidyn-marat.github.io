This repository provides tools to construct spatially embedded network topologies exhibiting tunable spatial self-similarity. It enables controlled analysis of how the fractal dimension $D$ governs routing efficiency, connectivity, and throughput in wireless mesh networks, reproducing the simulation framework from our paper *"The role of fractal dimension in wireless mesh network performance"* (*Scientific Reports*, 2025).
