Four dedicated Linux workstations configured for numerical modeling, machine learning, and offline language model inference. Each node runs an NVIDIA GeForce RTX 4070 Ti GPU paired with 32 GB of system memory.

The cluster handles direct N-body star cluster integrations, spatial network centrality calculations across Gaia DR3 catalogs, gravitational-wave signal classification training, and computer vision model benchmarking.
